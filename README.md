# Project: C++ PokerPal Card Game [Lab 1]
# Course: CSC-3420-1
# Date: 9/24/2026

## Description
A simple card game developed in C++ that simulates a standard 52-card deck. 
The program supports shuffling, dealing cards, and checking poker hand combinations.
Using C++ to create a card game, focus on Array2D and enum.

## Features
- Shuffle a 52-card deck using the Fisher-Yates algorithm.
- Deal 5 cards to the player.
- Check poker hands such as:
  - Pair
  - Two Pair
  - Flush
  - Straight

## Technologies
- C++
- Object-Oriented Programming (OOP)

## How to Run
Compile and run the program using a C++ compiler:

```bash
g++ main.cpp CardGame.cpp -o CardGame
./CardGame
```
